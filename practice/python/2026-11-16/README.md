## 실행 방법

날짜 폴더에서 아래처럼 실행한다. 문법 파일에서 각 함수를 직접 완성한 뒤 실행하면 main의 테스트가 예상값과 실제값을 비교한다. 테스트는 main에서 추가하거나 바꿀 수 있다.

```powershell
python syntax/01_참조와_복사.py
python syntax/02_자료구조와_정렬.py
python syntax/03_재귀와_스코프.py
python 01_재귀_타겟_넘버/solution.py
python 02_DFS_네트워크/solution.py
python 03_백트래킹_피로도/solution.py
```

문제 파일에서 `solution`을 완성하고 다시 실행하면 입력, 예상값, 실제값과 PASS/FAIL이 출력된다. 처음에는 미구현으로 표시된다. 문제 설명과 제한사항은 각 파일에 적힌 원문 URL에서 확인하자. 테스트 케이스는 파일의 `cases`에 추가할 수 있다.
