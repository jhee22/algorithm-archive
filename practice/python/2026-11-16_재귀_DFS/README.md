기존 SWEA 햄버거 풀이에서는 비트마스크로 부분집합을 열거했고, 트리 풀이에서는 명시적 스택으로 서브트리를 탐색했다. 비공개 학습 기록에서는 Java 컬렉션 기본 구현이 확인되지만 격자 탐색과 백트래킹의 독립 구현은 평가 전이었다. 직접 말해 준 시험 경험까지 고려하면, **탐색 개념을 알고 있으나 재귀 상태 설계·복원은 별도 확인이 필요한 단계**라는 가설이 적절하다. 코드만으로 시험 실력이나 현재 독립 구현 수준을 확정할 수 없다.

오늘은 Python으로 상태와 분기에 집중하자. Java 학습을 중단하라는 뜻은 아니다. 다음 복습 때 2번 또는 3번을 Java로 빈 파일에서 다시 구현해 언어 간 전이를 확인하자. 가까운 시험에서 사용할 언어가 정해져 있다면 그 언어로도 실전 연습해야 한다.

## Python 코테 도구 25분

각 코드를 직접 실행하기 전에 결과를 예측하고 왜 그런지 설명하자.

1. **참조와 복사**: `a = [[0] * 3] * 2; a[0][0] = 1; print(a)`를 예측한다. 독립 행이 되게 `[[0] * 3 for _ in range(2)]`로 고친다. `path`의 현재 상태를 결과에 저장할 때는 `result.append(path[:])`처럼 복사한다.
2. **튜플과 언패킹**: `r, c = (1, 2)`와 `for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):`로 이웃을 만든다. 좌표는 `(행, 열)`로 통일한다.
3. **list 스택 / deque 큐**: `stack.append(x)` / `stack.pop()`은 끝에서 추가·제거한다. BFS 큐는 `from collections import deque` 후 `append` / `popleft`를 쓴다. 리스트의 `pop(0)`은 나머지 원소를 이동하므로 반복 큐 연산에 부적합하다.
4. **set과 dict**: `seen.add((r, c))`, `(r, c) in seen`, `counts.get(key, 0)`을 연습한다. 해시 가능한 튜플은 set에 넣을 수 있고 리스트는 넣을 수 없다. 평균적인 조회는 O(1)이다.
5. **정렬 키와 집계**: `sorted([(2, 4), (1, 4), (3, 2)], key=lambda x: (-x[1], x[0]))`의 결과를 예측한다. `enumerate`, `sum`, `min`/`max`와 빈 입력의 처리도 확인한다.
6. **재귀와 스코프**: 내부 함수에서 바깥 지역 변수에 새 값을 대입하려면 `nonlocal`이 필요하다. 가능하면 재귀 결과를 `return`으로 합쳐 보자. 깊은 재귀는 `RecursionError`가 날 수 있다. 제한만 무작정 올리는 대신 깊이를 추정하고 깊은 격자 탐색은 명시적 스택을 고려한다.

## 문제 1 · 제한 합 부분집합 (25분)

서로 다른 위치의 양의 정수 `nums`와 양의 정수 `limit`이 주어진다. 합이 `limit` 이하인 부분집합의 개수를 반환하라. **빈 부분집합을 포함**하고, 값이 같아도 인덱스가 다르면 다른 선택이다. `0 <= len(nums) <= 20`, `1 <= nums[i] <= 100`, `1 <= limit <= 2000`. 재귀로 포함/제외를 구현하라.

```python
def count_subsets(nums, limit):
    pass

assert count_subsets([], 5) == 1
assert count_subsets([1, 2, 3], 3) == 5
assert count_subsets([2, 2], 2) == 3
assert count_subsets([7, 8], 1) == 1
```

양수라는 조건에서 현재 합이 limit를 넘으면 그 분기를 종료해도 된다. 최악 시간 O(2^n), 재귀 공간 O(n)을 목표로 한다. 각 인덱스에서 두 분기를 어떻게 합치는지 설명하자.

## 문제 2 · 충전 구역 (35분)

직사각형 `grid`에서 1은 이동 가능한 칸, 0은 벽이다. 상하좌우로 이어진 1의 연결 요소 개수와 가장 큰 요소의 크기를 `(개수, 크기)`로 반환하라. 1이 없으면 `(0, 0)`이다. `1 <= 행, 열 <= 100`, 각 원소는 0 또는 1. 입력을 수정하지 말고 **명시적 스택 DFS**를 사용하라.

```python
def charging_zones(grid):
    pass

assert charging_zones([[0]]) == (0, 0)
assert charging_zones([[1]]) == (1, 1)
assert charging_zones([[1, 0, 1], [1, 0, 1], [0, 0, 1]]) == (2, 3)
assert charging_zones([[1, 1], [1, 1]]) == (1, 4)
g = [[1, 0], [1, 1]]
assert charging_zones(g) == (1, 3) and g == [[1, 0], [1, 1]]
```

각 칸과 간선은 상수 번만 확인하도록 O(행×열) 시간과 공간을 목표로 한다. 이 문제의 방문은 **전체 탐색 동안 유지**한다. 대각선은 연결되지 않는다.

<details><summary>힌트 1</summary>
모든 칸을 순회하며 방문하지 않은 1에서 새 DFS를 시작한다.
</details>
<details><summary>힌트 2</summary>
스택에 넣을 때 방문 처리하면 같은 칸이 중복 삽입되지 않는다. 각 DFS에서 꺼낸 칸의 수를 센다.
</details>

## 문제 3 · 정확히 K번 이동하는 경로 (45분)

`grid`의 1은 이동 가능한 칸, 0은 벽이다. 왼쪽 위 `(0, 0)`에서 오른쪽 아래까지 상하좌우로 **정확히 k번 이동**하는 서로 다른 경로의 수를 반환하라. 한 경로에서 같은 칸은 두 번 방문할 수 없다. 시작·도착이 벽이면 0이다. 도착한 순간 경로가 끝난다. 시작과 도착이 같은 한 칸 격자에서는 k=0일 때만 1이다. `1 <= 행, 열 <= 5`, `0 <= k <= 12`. 입력을 수정하지 말고 재귀 백트래킹을 사용하라.

```python
def count_paths(grid, k):
    pass

assert count_paths([[1]], 0) == 1
assert count_paths([[1]], 2) == 0
assert count_paths([[0]], 0) == 0
assert count_paths([[1, 1], [1, 1]], 2) == 2
assert count_paths([[1, 1], [1, 1]], 3) == 0
assert count_paths([[1, 0], [0, 1]], 2) == 0
assert count_paths([[1, 1, 1], [1, 1, 1]], 5) == 1
```

방문은 **현재 경로에서만** 유지한다. 한 선택이 끝나면 다음 선택을 위해 복원하자. 최악 시간 O(4^k), 공간 O(행×열 + k)로 추정한다. 선택적으로 남은 이동 횟수보다 맨해튼 거리가 크면 가지치기해 보자.

<details><summary>힌트 1</summary>
상태는 현재 좌표, 사용한 이동 횟수, 현재 경로의 방문 상태다. 시작 칸을 방문 처리한다.
</details>
<details><summary>힌트 2</summary>
다음 칸 방문 표시 → 재귀 → 방문 해제 순서를 지킨다. 도착하면 이동 횟수가 k인지 바로 판정하고 더 진행하지 않는다.
</details>
