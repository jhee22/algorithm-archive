# 단계별 힌트

정답 코드는 없습니다. 막힌 문제의 첫 번째 힌트부터 읽고 직접 작성해 보세요.

## 리스트 / 맵 / 집합

1. 짝수 목록: 결과를 담을 `ArrayList<Integer>`를 만들고 입력을 앞에서부터 확인하세요. 나머지 연산으로 짝수를 구분하고 `add`로 담습니다.
2. 단어 빈도: `HashMap<String, Integer>`를 사용하세요. 각 단어의 기존 횟수는 `getOrDefault(단어, 0)`으로 읽고 `put`으로 갱신합니다.
3. 처음 중복되는 값: 왼쪽부터 확인하며 이미 본 값을 `HashSet<Integer>`에 기록하세요. `add`의 반환값 또는 `contains`를 활용할 수 있습니다.

## 큐 / 스택 / 힙

1. 큐: `ArrayDeque<Integer>`에 `offer`한 뒤 `poll`하면서 결과 리스트에 담습니다. 먼저 들어간 값이 먼저 나옵니다.
2. 올바른 괄호: 여는 괄호를 스택에 넣고 닫는 괄호를 만날 때 비어 있는지 확인하세요. 모두 처리한 뒤에도 스택이 비어 있어야 합니다.
3. 작은 수 k개: `PriorityQueue<Integer>`에 값을 넣고 k번 꺼내 결과에 담습니다. 중복도 별도 값으로 취급하세요.
