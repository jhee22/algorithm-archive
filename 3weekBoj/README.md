## 성취도 기록

| 등급 | 최초 시도에서 관찰한 행동 |
|---|---|
| L0 | 접근 불가. 제한 시간에 설계가 서지 않아 막힌 조건을 기록했다. |
| L1 | 핵심 힌트를 받아 해결했다. |
| L2 | 접근은 자력으로 정했고 구현·디버깅에서 도움을 받았다. |
| L3 | 힌트 없이 설계·구현을 끝내고 직접 만든 반례로 검증했다. |

손대지 않은 문제는 미시작이다. 시간 안에 일부만 구현해 위 기준을 판정하기 어려우면 ‘미완·판정 보류’와 그 이유를 적는다. 날짜별 기록에는 설계, 도움 내용, 실측 시간, 최소 입력과 기대값·실제값, BOJ 판정을 따로 남긴다. 재시도 전에 최초 기록을 고정한다. 이후 날짜에도 [11/23 기록표](2026-11-23/review.md)를 복사해 쓸 수 있다.

**최초 L3 비율**은 신규 중 최초 등급이 기록된 고유 문제의 L3 수 ÷ L0~L3 수다. 미완·보류 수와 미시작 수도 함께 남겨 분모가 줄어든 이유를 알 수 있게 한다. 분모가 0이면 미측정이다. **재풀이**는 빈 파일에서 같은 반례를 통과했는지와 도움 유무를 기록하고 최초 등급을 덮어쓰지 않는다.
