## 각 문제를 풀 때

| 단계 | 14940 | 14891 | 직접 남길 내용 |
|---|---:|---:|---|
| STEP 0 · 문제 해석 | 5분 | 10분 | 입력·출력, 상태의 뜻, 종료 조건, 예외 조건을 적는다. |
| STEP 1 · 설계 | 5분 | 10분 | 사용할 자료구조와 주요 함수의 역할을 쓰고 선택 이유를 한 줄로 남긴다. |
| STEP 2 · 독립 구현 | 30분 | 35분 | 연습 파일의 `solve`를 완성한다. 처음 막힌 위치와 도움을 받은 시각을 남긴다. |
| STEP 3 · 검증 | 10분 | 15분 | 직접 만든 작은 입력에서 기대값을 먼저 쓰고 실행한다. 실패 원인과 시간·공간 복잡도를 설명한다. |

## 실행과 기록

저장소 루트에서 한 파일을 실행한 뒤 원문의 입력 한 세트를 붙여 넣는다. 처음 제공되는 파일은 입력을 읽고 끝난다. `solve`에 반환값을 작성하면 답이 표준 출력에 표시된다.

```powershell
python 3weekBoj/2026-11-23/14940.py
python 3weekBoj/2026-11-23/14891.py
```

두 문제를 마치면 20분 동안 [최초 시도·재풀이 기록표](review.md)에 결과를 적는다. 위 표의 상태를 갱신하고 11/25에 다시 확인할 반례를 하나 고른다.
