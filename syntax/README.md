# 주제별 문법과 구현 연습

연습 파일은 주제별 폴더에 모아 VS Code에서 직접 열고 실행합니다. 한 파일에 여러 주제가 있으면 대표 주제로 분류합니다.

- Collections: [Python](Collections/syntax1.py) · [Java](Collections/syntax1.java)
- [Reference](Reference/syntax1.py): Python 리스트 참조와 복사
- [Recursion](Recursion/syntax1.py): Python 재귀 반환값과 스코프
- [Queue](Queue/syntax1.java): Java 큐, 스택과 힙
- [Sort](Sort/syntax1.java): Java 집계와 정렬
- [Heap](Heap/syntax1.java): Java 우선순위 대기열
- [String](String/syntax1.java): Java 문자열과 스택
- [SlidingWindow](SlidingWindow/syntax1.java): Java 연속 구간

새 파일은 `syntax/<주제>/syntax1.py`, `syntax2.py`처럼 번호를 붙입니다. Java도 같은 주제에 `syntax1.java`처럼 두고 클래스 이름을 파일 이름과 일치시킵니다. 같은 이름의 Java 클래스는 각 폴더에서 개별 실행합니다.

날짜별 학습 계획과 힌트, 복습 기록은 [records](records/)에서, 플랫폼 풀이는 `solutions/<언어>/<플랫폼>/`에서 찾습니다. [Java 연습과 주간 계획](records/java/README.md)에서 날짜별 세트로 이동할 수 있습니다.
